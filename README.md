# HP Simple Modeling Tools v0.27.5

Blender 4.3 以降向けアドオン。元の v0.26.29 ZIP はそのまま残しています。

## インストール

Blender の「プリファレンス → アドオン → ディスクからインストール」で
`HP_SimpleModelingTools_PathPen_v0.27.5_SectionWindow.zip` を選択してください。
既存の HP Simple Modeling Tools と旧単体版を無効化し、更新後に Blender を再起動してください。
ZIP 内の個別 `.py` はインストールしないでください。

## 断面エディター

A/B に加えて、同じビュー内に独立した3Dパネル **C** を表示します。
小さな補助用の別ウィンドウは作りません。広いビューでは A/B/C を横並びにし、
狭いビューでは C を B の上に配置します。
ビュー内のパネルは左下を基準に、操作設定用の余白を取って配置します。
Blender が公開する「最後の操作を調整」の領域が大きい場合は、その上へ移動します。

C は通常／シーン全体モードでは「断面のみ」、別ウィンドウの断面のみモードでは「シーン全体」です。
A/B と同じ背景グリッド、青い線・点、橙色の選択点と番号を表示します。
C の上ではテンキー 1/3/7 で方向、5 で透視／平行投影を切り替え、Home／テンキー小数点で断面を収めます。
中ボタンで回転、Shift+中ボタンでパン、Ctrl+中ボタンまたはホイールでズームします。
C の視点は元の3Dビューと独立し、モード切り替えでも引き継ぎます。
点のクリック／ボックス選択、ドラッグ、G/S/R、Eブラシ、Fペン、取り消しも A/B と共有します。
C の「シーン全体」は簡易表示で、表示中のメッシュ・カーブなどの面と辺、画像エンプティを描画します。
マテリアル・ライティング・Blender標準の全オーバーレイは再現しません。

3D ビューの **右クリック → HP 断面エディター** から操作します。
「ビュー内に切り替え」「別ウィンドウ：断面のみ」「別ウィンドウ：シーン全体」
「断面エディターを閉じる」を選べます。
点を選択したままで切り替え・終了でき、先にエディターを閉じる必要はありません。
切り替え時は選択点・設定・Undo 履歴を引き継ぎます。別ウィンドウを繰り返し選んでも重複しません。
F3 から「HP Section: 別ウィンドウに切り替え」を検索しても操作できます。
ブラシ／ペン／移動操作中の右クリックは従来どおりキャンセルとして働きます。

Windows の複数モニター環境では、別ウィンドウを開くと元の Blender ウィンドウとは別の
モニターへ自動配置します。左側や上側に置いたモニター、タスクバーを考慮します。
配置処理は新しく作成した Blender ウィンドウだけを対象にし、他のアプリは動かしません。
モニターが1台の場合は移動しません。配置を取得できない場合は通常位置で開き、手動移動できます。
この自動配置は Windows 向けで、Windows 実機での確認は未実施です。

N パネルの操作は初期状態では非表示です。必要ならプリファレンス → アドオン →
HP Simple Modeling Tools の「Nパネルにも断面エディター操作を表示」を ON にしてください。
「別ウィンドウを別モニターに配置（Windows）」で自動配置も切り替えられます。

- 「断面のみ」は、下部に A/B、残りに選択した頂点列だけの 3D 表示を出します。
- 「シーン全体」は元の3Dビューと同じシーン・オブジェクトをサブウィンドウに表示します。
  作成時の視点を引き継ぎ、その後の視点は各ウィンドウで独立して動かせます。
  3D部分ではテンキー 1/3/7 の視点切り替え、5 の透視／平行投影切り替え、0 のカメラ表示、
  中ボタンでの回転・パン・ズーム、選択・編集に Blender 標準の操作を使えます。
  A/B の上にマウスを置いた場合は従来どおり断面ビューの操作です。
  右クリックから「断面のみ」と「シーン全体」を同じサブウィンドウ内で切り替えられます。
  断面だけの表示から戻すと、全体表示の視点・オブジェクト表示設定を復元します。
  データは共有されるので、どちらのウィンドウでの編集も元のシーンに反映されます。
- 元のウィンドウで編集モードの連続した辺の列・閉じたループを選ぶと対象が切り替わります。
- 選択がないときは待機します。選択解除やオブジェクトモードへの移行でウィンドウは消えません。
- 3D プレビューは中ボタンで回転、Shift+中ボタンで移動、Ctrl+中ボタンでズームできます。
  3D 表示内でもクリック／Shift+クリック／空白からのドラッグで点を選択できます。
  点のドラッグ、G 移動、S 拡大縮小、R 回転に対応します。G/S/R 中の X/Y/Z はワールド軸指定です。
  左クリック／Enter で確定、Esc／右クリックで取り消し、Ctrl+Z で断面ビューと共有の Undo を使えます。
  A は全点選択、Alt+A は選択解除です。選択は A/B と共通です。
  E ブラシと F ペンも利用できます。ペンは左ドラッグで描き、F／Enter で適用します。
  描画済みの線は E ブラシで調整でき、ブラシ中の Esc／右クリックで調整前の線へ戻ります。
  ペンは現在の視点で投影した形を適用し、各点の奥行きを保持します。
  3D でのトポロジー編集や共有調整メニューは A/B から操作してください。
- 断面ビューで選択した点を橙色と番号で表示します。同じ番号がもう一方の断面ビューと
  元の 3D ビューにも表示されるため、動かさずに対応を確認できます。
- A/B は従来より大きい 480×360 を基準に始まり、画面に収まるよう調整されます。ビュー内で `+` / `-` を押すとサイズを変更できます。
  ヘッダーをクリックすると折りたためます。
- 「ビュー内に切り替え」も利用できます。断面ビューは右上に配置します。
- 右クリックの「断面エディターを閉じる」で終了します。別ウィンドウの場合はその窓も閉じます。
  開いた状態は Blender の現在のセッション内で維持されます。Blender 再起動後は開き直してください。

円追加直後の左下の数値設定と競合しないように、断面／カーブエディターの**自動起動を廃止**しました。
必要なときに右クリックメニューから開いてください。パネル外のキー入力は Blender に渡します。
カーブエディターは F3 で「HP Curve Mini Editor」を検索して開けます。
N パネルを有効にした場合は HP Tools の「カーブエディターを開く」も使えます。
カーブエディターも従来より小さいサイズで右上に表示されます。

## E ブラシとペン

E を押しながら動かすブラシは、従来どおりドラッグ方向に点を動かします。
今回の変更ではブラシ境界の影響を滑らかにゼロへ減衰させ、マウスが通った経路に沿って処理します。
速く動かしたときの取りこぼしや、イベント密度による変形量の違いを抑えています。
断面の点、未確定のペン線、カーブの点に適用しています。

断面の E ブラシはホイールで半径、Alt+ホイールで強さを調整します。
E を離すと確定、Esc／右クリックでその操作前に戻します。
ペン線は F で描画モード、F／Enter で適用、Shift+F で解除します。
既存のペン補正、開いた線の端点保持、Mirror Clipping は維持しています。
その他の操作は [アドオン同梱の説明](HP_SimpleModelingTools/README.txt) を参照してください。

## 開発と検証

編集可能なソースは `HP_SimpleModelingTools/` に展開しました。
通常の Python ではなく Blender の Python で実行してください。

```sh
# 数値アルゴリズムのテスト（ウィンドウ関連のケースは skip）
blender --background --factory-startup --python-exit-code 1 --python tests/test_section_editor.py

# 全テスト。ディスプレイが必要です。クラウドでは Xvfb でも実行できます。
blender --factory-startup --python-exit-code 1 --python tests/test_section_editor.py

# ZIP の再生成
python tools/package_addon.py
```

Blender 4.3.2 と Xvfb で全テストを実行しています。
別ウィンドウ生成、選択解除／再選択、オブジェクト切替、パネル外入力、回転操作の解放、
ブラシ・ペンのキャンセル、Mirror Clipping、カーブエディター、3D での選択・G/S/R・
軸指定・Undo・ペン適用・右クリックの入力受け渡し・表示モードの切り替え・
モニター選択／配置計算・Windows API 呼び出し経路（モック）を検証対象にしています。
物理的な複数モニターでの移動や操作感は利用環境で確認してください。
